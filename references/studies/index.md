# Five-film reference study

All 5,823 frames were decoded and indexed without resampling time. All consecutive overview sheets were visually inspected. This is all-frame overview analysis at 160×90, with a separate 640×360 decode for the final side-by-side film (320×360 per half). It is not a claim that every full-resolution pixel or every easing coefficient has been examined. Motion intervals and uncertainties are indexed in the accompanying JSON files; reference images remain private.

The final source has 719 frames at 60000/1001 fps; frame 718 has PTS 11.978633 seconds. Do not calculate its timestamps as frame/60. The first source has no audio track. The other four have audio but have not been actually listened to in this session. Waveform/onset analysis is not substituted for listening.

The transferable insight is causal object continuity: a selected subject survives, changes state, lands, is read, then hands attention to the next subject. Alternate dense bursts with sparse readable passages. Use original assets and verified product relations.

Enlarged continuous checks cover 528 selected frames: revenue transition/counter (393–468), script approval (432–564), shape morph (345–450), spatial focus/settings (630–780), and two-card relay (427–488). These phase records improve the overview with measured action boundaries; unmeasured microphases in other intervals remain explicitly indeterminate. Every overview conclusion links consecutive all-frame sheets in the private evidence index.
