# Motion that explains the product

For each shot identify the subject, starting state, trigger, main motion, response, hold, and next visual anchor. Selection should carry the chosen object into its result. Expansion should preserve the viewer's understanding of where the object came from.

Use anticipation, acceleration, stagger, and damping deliberately. A spring is a curve, not a reason for everything to bounce. Reserve the strongest movement for important meaning. Alternate energetic passages with readable holds; fixed equal-length shots are rarely a useful default.

Connect major visual landings to musical accents using the shared event timeline. The movement can start before a beat and arrive on it. Avoid sound effects on every letter or permanent background pulsing. Inspect a short actual render of the difficult handoff before extending the film.

The stage is usually a low-contrast gradient, light texture, or local halo made with code. At most one moving element should dominate attention. Keep accurate UI text independent of decorative surfaces. Real recordings, captured screenshots, reconstructed UI, and authored navigation each need the appropriate evidence description.
