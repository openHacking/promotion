# Animated templates

Show the complete playable gallery before recommending a template unless the user already selected a direction. The gallery uses original fictional products, not proof of real software behavior.

| ID | Structure | Suitable products |
|---|---|---|
| minimal | Brand, hero, staggered capabilities, interface focus, close | Apps, design tools, launches |
| window | Intent, workspace expansion, operations, output, close | Desktop apps, agents, development tools |
| command | Large promise, typed command, selection, instant output, close | Search, launchers, shortcuts |
| workflow | Input, connected steps, output consolidation, value, close | SaaS, automation, knowledge, collaboration |

Replace brand, copy, palette, font, assets, durations, and sound. Change the choreography when the product's behavior differs. The window template is a general desktop workflow; it does not require a device panel.

Freeform `story` supports arbitrary shot counts and captured browser surfaces. See docs/project-guide.md and the SaaS Hunt example.
