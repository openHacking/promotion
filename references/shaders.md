# Optional frame-locked shaders

The pinned shaders dependency supplies an optional WebGPU material for the dynamic window template. Enable it with `--shader` only when a subtle animated material helps the subject. Keep contrast low and stop or soften movement during reading.

The bake script renders a local shader video, reused by the final composition. No live network calls or wall-clock uniforms should drive export. GPU compatibility varies; the default SVG/CSS background is the supported fallback. The freeform SaaS Hunt film uses no shader or generated stage image.
