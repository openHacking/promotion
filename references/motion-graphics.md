# Motion graphics route

Use MG when the idea is a relationship, selection, sequence, transformation, or punchy verbal proposition. Choose factual UI for proof and generated subjects for a concrete visual need. These are production routes, not fixed artistic styles. Code animation works in Codex and other agents with an available rendering runtime; do not assume a particular agent has hidden capabilities.

## Playable starting points

Three original recipes live in `src/MotionGraphics.tsx`: `orbit` (path movement, depth sorting, selection and expanding carrier), `elastic` (staggered spring type, SVG stroke drawing, card collapse and fan), and `split` (staggered strip masks revealing accurate image layers). Use `story` shots with `kind: "mg"` and `mg: {recipe, headline, label, items, selected, file}`. Mix these with scene or UI shots. Configuration is validated before rendering. Change source choreography when a recipe cannot explain the message.

Render a standalone starter with `python3 scripts/example.py new-project --variant mg`, then replace its config with one of `examples/mg-templates/*.json`. Keep the source assets and installed runtime from the initialized project. Each starter is ten seconds, editable, and uses the same local licensed soundtrack. The starters are motion studies, not claims about a real interface.

References: [Jitter templates](https://jitter.video/templates/), [Orbit cards](https://jitter.video/template/orbit-cards/), [Split reveal](https://jitter.video/template/the-edit-split-reveal/), and [Text stretch](https://jitter.video/template/stretch-snap-text/). Study timing, hierarchy, continuity, anticipation, contact and recovery from moving footage. These references are not bundled artwork or copied template implementations.

## Choreography requirements

Design the object chain: stimulus → response → transfer → reading hold. Vary motion mechanisms and shot scale; avoid a succession of nearly identical panels. Use overshoot selectively, not on factual text or every object. Do not mistake an easing preset for narrative. Keep action bursts short and reserve stable holds for evidence. A moving screenshot is editorial presentation, not evidence that an action actually occurred.

Review the encoded transition before the full render. Reject cut-off cards, unreadable labels, exposed masks, static empty intervals, unmotivated movement, and unsupported product claims. Listen separately; an audio stream or peak check is not a listening pass.
