# Repository guidance

Use the local Promotion skill in SKILL.md when working on this repository. Keep source documentation, comments, CLI messages, and public examples in English. Preserve multilingual test coverage with Unicode escapes. Do not change other installed skills.

Run type checks and relevant tests after code changes. Render animation changes and review the encoded output. Keep automated checks, visual review, and listening evidence separate. Never include private paths, secrets, or unrelated project branding in public reports.
