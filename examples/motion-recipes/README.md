# Eight original motion recipes

Each MP4 is a six-second silent internal study at 1920×1080, 60fps. Every mechanism has a second render with different labels and accent. These are editable mechanical demonstrations, not finished promotional films.

| Purpose | Study | Replacement |
|---|---|---|
| Word/label priority and masked reveal | [Type](type.mp4) | [Replacement](type-replacement.mp4) |
| Quadratic path travel | [Path](path.mp4) | [Replacement](path-replacement.mp4) |
| Rounded geometric transformation | [Morph](morph.mp4) | [Replacement](morph-replacement.mp4) |
| Membership and aggregation | [Aggregate](aggregate.mp4) | [Replacement](aggregate-replacement.mp4) |
| Selection and visible-set change | [Filter](filter.mp4) | [Replacement](filter-replacement.mp4) |
| Selected card focus | [Expand](expand.mp4) | [Replacement](expand-replacement.mp4) |
| Dependency connector drawing | [Flow](flow.mp4) | [Replacement](flow-replacement.mp4) |
| Collection depth and travel | [Spatial](spatial.mp4) | [Replacement](spatial-replacement.mp4) |

The renderer is `assets/remotion/scripts/render-recipes.mjs`; the editable component is `assets/remotion/src/MGSystem.tsx`. Recipe parameters and failure conditions are documented in [motion recipes](../../references/mg-recipes.md). Frame-time poses are stateless and tested under out-of-order evaluation. Aggregation rows were widened after encoded inspection found overlap. A spatial loop is appropriate for a collection, but needs a separate focus hold when the viewer must read a particular card. Morph text is incidental texture; it must not contain essential product claims.
